# 💸 Expense Tracker

A full-stack expense tracking application built with **HTML, CSS, JavaScript, Python, FastAPI, and SQLite**.

The application allows users to manage their expenses, organize them into categories, and keep track of their spending.

## ✨ Features

- ➕ Add new expenses
- ✏️ Edit existing expenses
- 🗑️ Delete expenses
- 📋 View all expenses
- 🏷️ Organize expenses by category
- 🔍 Filter expenses by category
- 📅 Filter expenses by month or custom date range
- 💰 Calculate total spending
- 📊 Calculate average daily spending
- 🏆 Display the category with the highest spending

## 🛠️ Tech Stack

**Frontend**
- HTML

- JavaScript

**Backend**
- Python

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:
- Python 3.10 or newer
- A modern web browser

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
cd Expense
```

### 2. Start the Backend 🐍

Install the required packages:

```bash
pip install fastapi uvicorn pydantic
```

Run the backend:

```bash
uvicorn backend.app:app --reload
```

Backend address:

http://127.0.0.1:8000

API documentation:

http://127.0.0.1:8000/docs

### 3. Start the Frontend 🌐

Open the `frontend` folder and launch `index.html` in your browser.

The frontend communicates with the backend through HTTP requests.

## 🔌 API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/expenses` | Get all expenses |
| POST | `/expenses` | Create a new expense |
| PUT | `/expenses/{id}` | Update an expense |
| DELETE | `/expenses/{id}` | Delete an expense |

## 📦 Expense Data Structure

Each expense contains:

```json
{
  "id": 1,
  "name": "Coffee",
  "price": 3.50,
  "category": "Food",
  "date": "2026-11-23"
}
```

The expense ID is generated by the database.

## 🏗️ Application Architecture

```text
       HTML + CSS + JavaScript
                  |
                  | HTTP Requests
                  v
               FastAPI
                  |
                  v
                SQLite
```

The frontend handles the user interface and interactions. FastAPI handles the application logic and communicates with the SQLite database.
